# 🧩 HTML Tables Task

## 🎯 Goal

Create an HTML page that displays a **Weekly Class Schedule** using an HTML `<table>`.

## 📋 Requirements

Your table should include:

* A `<caption>` for the table title.
* A table header using `<thead>`.
* At least **5 columns**.
* At least **6 rows** of data.
* Use `<th>` for table headings.
* Use `<td>` for table data.
* Use `<tr>` for table rows.
* Use `colspan` at least **once**.
* Use `rowspan` at least **once**.
* Add a `<tfoot>` containing a short note about the schedule.

## 📝 Example Data

Create a schedule similar to this:

| Day       | Time     | Subject    | Instructor | Room     |
| --------- | -------- | ---------- | ---------- | -------- |
| Sunday    | 9:00 AM  | HTML       | Ahmad      | Lab 1    |
| Sunday    | 11:00 AM | CSS        | Sara       | Lab 2    |
| Monday    | 9:00 AM  | JavaScript | Omar       | Lab 1    |
| Tuesday   | 10:00 AM | Database   | Lina       | Room 203 |
| Wednesday | 9:00 AM  | Python     | Khaled     | Lab 3    |
| Thursday  | 11:00 AM | Project    | Team       | Room 105 |

> **Note:** The data above is only an example. You can create your own schedule and subjects.

## ⭐ Bonus Challenge

Add a **"Break"** row that spans across all columns using `colspan`.

Also, make one subject span across two days using `rowspan`.
