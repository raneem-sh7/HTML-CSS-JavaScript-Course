# HTML Task 2 — Improve Personal Profile Page

## Task Description

Improve the **Personal Profile Page** created in Task 1 by applying the new HTML concepts learned in Lesson 2.


## Requirements

* Keep the main structure and content from **Task 1**.
* Use the `style` attribute to improve the appearance of different elements.
* Change properties such as:

  * `color`
  * `background-color`
  * `font-size`
  * `text-align`
  * `font-family`
  * `width`
  * `height`
* Use `<b>` to emphasize important text.
* Use `<em>` to emphasize a word or idea.
* Use `<small>` for less important or additional information.
* Use `<del>` to represent outdated, removed, or no-longer-relevant information.
* Make the page more visually organized while keeping it **HTML only**.

## Challenge

Try to improve the page **without looking back at the lesson example**.

Focus on using the new tags and styling properties in a meaningful way rather than simply adding them to satisfy the requirements.

## Expected Result

The final webpage should be an improved version of the **Task 1 — Personal Profile Page**, with:

* The original profile content
* Improved visual styling
* Meaningful use of text-formatting tags
* A clear and organized layout
* Inline styling using the `style` attribute

## Technologies

* HTML
* Inline CSS using the `style` attribute

## Learning Focus

This task focuses on practicing:

* HTML `style` attributes
* Basic CSS properties
* Text formatting tags
* Improving an existing webpage using newly learned concepts
