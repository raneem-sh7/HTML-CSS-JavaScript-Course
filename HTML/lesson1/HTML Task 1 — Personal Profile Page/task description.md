# HTML Task 1 — Personal Profile Page

## Task Description

Create a simple personal profile webpage using **HTML only**.

## Requirements

- Create the basic HTML document structure.
- Add a page title using `<title>`.
- Add headings using `<h1>`, `<h2>`, and `<h3>`.
- Add paragraphs using `<p>`.
- Use `<br>` to create a line break.
- Add a link to Google using `<a>` and the `href` attribute.
- Add an image using `<img>` and the `src` attribute.
- Use `<pre>` to display your goals while preserving spacing and line breaks.

## Challenge

Try to build the webpage **without looking back at the example code**. Use what you learned from the lesson to create the page yourself.

## Expected Result

The webpage should include:

- Personal name/profile heading
- About Me section
- My Skills section
- My Goals section
- Google link
- Image
- Goals displayed using `<pre>`
